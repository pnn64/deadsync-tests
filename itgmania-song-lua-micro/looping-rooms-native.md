# Looping the Rooms native rendering reference

`looping-rooms.ssc` is the unchanged non-Lua "Looping the Rooms (ITL edit)"
Challenge 9 / XMOD chart by Cookie. Its SHA-256 is
`1eee29b98fcc7e8a8972676dc2a30bfbf7bc78d1c5fcd36406b27797412281ff`.
The native chart loader reports BPM 162, beat-zero offset 0, last note second
131.11884 and GrooveStats hash `116d1c6ed096d6ae`.

`looping-rooms-native.json.zst` retains actual ITGmania receptor and note
submissions around four reported differences. It contains no expected poses
generated by DeadSync. The capture used harness 0.1.110, clean ITGmania revision
`663525dcb86eb570d0ef6a2e209678436660ae26`, the unchanged chart and its original
OGG, OpenGL at 854 by 480, P1 Cel, M690, -10% Mini, music rate 1, ITG sync
offsets, global offset -0.008 seconds and zero visual delay. FastNoteRendering
was explicitly enabled and verified at the start and end. The native window
remained hidden. Background images/video were not staged; this reference tests
the notefield rather than media playback or foreground occlusion.

## Retained intervals

Simply Love's `ScreenGameplay underlay/PerPlayer/StepStatistics/Time.lua`
subtracts `SongPosition:GetMusicSeconds()` from `Song:GetLastSecond()` and
formats the remaining value using `SecondsToMSS`. Native `RageUtil.cpp`
truncates its fractional seconds. Using the chart's native last-second value,
the reported countdowns map to these approximate music-time ranges.

| Reported countdown | Approximate music seconds | Authored transition | Retained draw seconds |
| --- | --- | --- | --- |
| 1:34 | (36.11884, 37.11884] | MoveX separation attack ends at 35.926; Current approaches Stage while MoveY attacks remain active | 35.4-37.4 |
| 1:01 | (69.11884, 70.11884] | Zigzag and ZigzagPeriod attack ends at 70; ZigzagOffset and Stealth attacks continue to 71.111 | 69.4-71.4 |
| 0:47 | (83.11884, 84.11884] | Dark attack ends at 83.333; receptors fade back while staggered MoveY attacks begin | 82.8-84.5 |
| 0:00 | From approximately 130.11884 onward | MoveX/MoveY plus indexed ConfusionXOffset attacks begin at 130, 130.375, 130.75 and 131.104167 | 129.8-131.5 |

All 4,392 native update frames and all three original mesh definitions are
retained. The four intervals retain 235 complete draw frames: 940 receptor
visits, 1,739 sprite/strip submissions and 2,924 Model submissions. No selected
draw or sample value was synthesized or rounded. Only the cumulative sample
counts in frame-boundary arrays were rebased after excluding other draw
frames. The document's `extraction` object records this transformation, the
full capture's SHA-256 and size, the original counts and the selected ranges.

`ArrowEffects::GetRotationX` without selecting by note type.
`ArrowEffects.cpp:1036-1049` applies indexed ConfusionXOffset through
`ReceptorGetRotationX`; the hold-cap condition only affects Roll.
`ArrowEffects.cpp:1115-1126` converts the indexed X offset from radians to
degrees. The absence of a tilted standalone tap in this autoplay capture does
not narrow that implementation contract to hold heads.

## Native field placement

Simply Love's `metrics.ini:1811-1816` places the P1 field metric at
`_screen.cx - clamp(_screen.w, 640, 854) * 0.25`, which is 213.5 for the
854-pixel logical width. The engine derives its final field center from margins
rather than assigning that metric directly. The fallback theme's
`Scripts/03 Gameplay.lua:41-77` uses a 272-pixel fake style width and returns
combined left, center and right margins of 77.5, 155 and 77.5 for this setup.

`GameplayHelpers.cpp:48-53` reads those Lua values with `SafeFArg` and divides
the center margin between the players. Despite its name, `SafeFArg` returns an
integer and truncates the Lua number (`LuaManager.h:276-278`). Thus the outer
margins become 77 while each inner margin remains 77.5. The placement formula
at `ScreenGameplay.cpp:640` is `edge + left_margin + field_space / 2`, giving
P1 X = 213.25 and P2 X = 640.75. The retained native geometry reflects this
quarter-pixel offset. It is a consequence of the source's numeric conversion,
not a correction estimated from the captured poses.

## Clock and comparison contract

The shell regression
`looping_rooms_matches_native_attack_transitions_and_final_tilt` replays all
recorded update frames through ordinary non-Lua gameplay and compares its own
rendered output with the retained submissions. Only observed clock inputs
enter gameplay. Current modifiers, actor transforms, note positions and
opacity must come from the unchanged SSC and normal update/composition paths.
Native mesh vertices identify the submitted Cel meshes; native transforms are
not injected. Native Current options are not sampled every frame in this
protocol; receptor alpha and submitted vertices are independent output
observations. `option_deltas.players` are the actual native ModsGroup timer
inputs, separate from `delta`, music seconds and wall time.

Attack timing also has a native phase boundary. `GameState::Update` calls
`PlayerState::Update` before Screen updates; attack activation uses the player
song position already present at that point. `ScreenGameplay::Update` then
refreshes the music/song position used by that frame's drawing. Consequently,
the new draw clock must not be supplied as though it had already been present
when that frame's attacks were updated. This is visible at 131.115753 seconds:
the up-column attack at 131.104167 has not yet affected the receptor in that
draw. The next frame updates it using the newer music position.

Model submissions retain full homogeneous clip bases, original mesh vertices,
native draw sequence, material color and effective OpenGL render state.
Sprite/strip vertices retain raw XYZ, clip XYZW, UV and RGBA. Receptor visits
remain present even when their alpha is zero and no geometry is submitted;
draw associations use `receptor_visit_sequence`. The trace has no script errors
or dropped observations. The configured 60 FPS is a pacing ceiling, not a
claim of achieved frame rate; recorded deltas are authoritative.

The numerical comparison covers 892 normal-blend receptor quad submissions
and 2,856 Cel Model submissions: Tap, Fake and HoldHead parts 0, 3 and 4. The
other 68 Model submissions are mines and are outside this comparison. Each
selected frame must have matching draw counts, blend modes, texture-mask
modes, alpha, and homogeneous clip coordinates. Receptor corners are matched
bijectively to allow backend winding differences. Models compare their origin
and all three clip-space basis directions scaled by 32, retaining Z and W so
that flattening perspective is observable. The absolute clip-component
tolerance is 0.5; alpha tolerance is one 8-bit step plus 0.00001 for receptors
and 0.0001 for Models. All 12 fully hidden receptor frames have no native Model
submissions either.

Each interval also rejects a render with attacks disabled. These controls show
that attacks affect the compared output; they do not isolate each repaired
mechanism independently. This comparison does not check RGB, texture/UV
correctness, triangle topology, depth behavior, draw order or receptor additive
glow. It is a geometry/opacity contract, not a framebuffer parity claim.

Run the focused regression from the DeadSync checkout with:

```powershell
cargo test -p deadsync-shell looping_rooms_matches_native_attack_transitions_and_final_tilt -- --nocapture
```

## Reproduction

From the ITGmania harness checkout, stage the unchanged SSC and original OGG
together, then run the current adapter executable:

```powershell
target/debug/itgmania-harness-rs.exe song-lua-trace 'path/to/Looping the Rooms (ITL edit).ssc' `
  --itgmania-bin target/native-pinned-source/Program/ITGmania-harness-trace.exe `
  --headless --notefield-samples --style single --difficulty Challenge `
  --fallback-theme 'Harness Simply Love' --player-options 'm690, -10% mini, cel' `
  --fast-note-rendering 1 --drawable-from-beat 94 --until-beat 359 `
  --capture-fps 60 --max-events 1000000 --keep-run-dir --timeout 230 `
  --out target/looping-rooms-parity/native.json
```

Retain all update frames and mesh definitions. Select whole drawn frames whose
`visible_seconds` lies in the four inclusive intervals above; preserve every
Model, sprite/strip and receptor visit for each selected frame, and rebase
cumulative frame counts. Preserve the native provenance and add extraction
metadata identifying the original exported capture. Compress the resulting
JSON losslessly with Zstandard.

The reference covers these transitions, including ending receptor and
hold-head indexed X tilt.
It is not a framebuffer/pixel oracle, an observation of per-frame Current
modifier values, a media comparison, or a claim of whole-chart parity. The
ending sample stops at 131.5 seconds while the last MoveY attack continues.
