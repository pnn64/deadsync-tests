# Proxmox song Lua parity, 2026-11-19

This directory preserves the native capture validation, independent pipeline
controls, and frozen corpus inventory for the fourth Proxmox comparison round.
The initial evidence commit is a checkpoint while the full fleet is running.
It does not claim completed corpus coverage or that the patched DeadSync runner
has passed the controls. Later replay reports must identify their own exact
runner and source hashes.

## Corpus and capture scope

The frozen corpus combines the current installed Lua songs, distinct older
variants, and other installed Lua-bearing packs. Exact folder aliases are
deduplicated while distinct bytes are retained. It contains 582 simfiles in
455 canonical folders, 10,346 files, 1,920 Lua files, and 1,625 authored chart
headers. Native discovery, rather than header ordering, selects the actual chart
indices for replay.

Initial native discovery produced 1,620 supported jobs across dance single,
double, couple, routine, solo, and pump single/double profiles. One native
lighting chart has no supported playback profile. Two simfiles did not produce
a selectable catalog: Lesson by DJ.sm and a nested saved Cursed Metamorph.ssc.
Fifteen probes produced usable native catalogs before a later probe error;
their supported chart jobs remain included. `corpus/discovery-ledger.json`
records all 582 sources, their native catalog identities, selected jobs, and
exclusions. It also retains diagnostics for both unselectable sources: Lesson
by DJ has a `#NOTES` line missing its colon, and the nested Cursed Metamorph
directory contains only its SSC, without the music referenced by that file.
Both original source hashes were rechecked; neither source was changed.
The initial snapshot includes early running captures and eight baseline
diagnostic passes, not completed fleet coverage. Preserve this inventory when
adding any later recovery attempts.

Fifteen workers receive 106-109 jobs each. Captures use real offscreen OpenGL
through Xvfb, native timing, drawable capture, and raw gameplay timer inputs.
Capture identities are independent of the DeadSync replay binary so later
runner builds can reuse the same retained native input. Replay results are
accepted only for the requested runner hash and its verified source/build proof.
No aggregate result in this checkpoint establishes final fleet completion.
